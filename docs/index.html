ALE/MsPacman-v5 · DQN vs PPO · 1M steps per agent

DQN scores higher on the maze it trained on. PPO holds up better when the maze is mirrored.

We trained DQN and PPO agents on Ms. Pac-Man for a million steps each, with five seeds per configuration, and evaluated every agent on 200 episodes. DQN scores 11–26% more than PPO on settings A–C, but only the gap on A is clearly larger than the seed-to-seed noise. On a vertically mirrored maze DQN loses more than half its score, while PPO loses 15%. Each evaluation episode is one life, and it counts as a success at 1,000 points.

The experiment

One life, 1,000 points to win

We compare the two agents across four environment settings. A, B and C are each used for training and evaluation. D tests the agents trained on B on a maze they have never seen. Every evaluation episode ends at the first lost life, at 1,000 points (success), or after 5,000 steps (timeout).

Greedy vs sampled

Greedy DQN replays the same few games

Without sticky actions (setting A) the game is deterministic, so a greedy agent can only vary through the random no-op start. Greedy DQN played about 26 different games in 200 episodes. Each seed then either wins almost every time or almost never, which makes the five-seed average jumpy. Sampled PPO plays a new game nearly every episode.

Robustness · setting D

The mirrored maze breaks DQN more than PPO

The B agents were evaluated on a vertically mirrored maze, with UP and DOWN swapped so the controls still match what the agent sees. Both agents lose score. DQN loses far more.
